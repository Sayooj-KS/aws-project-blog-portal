# AWS Flask Blog Portal 🚀

A cloud-based Blog Portal built using Flask, AWS EC2, RDS MySQL, Gunicorn, Nginx, and Docker.

---

# 🌐 Live Project

http://13.239.54.94

---

# 📌 Features

- User Login & Register
- Create/Edit/Delete Posts
- Like System ❤️
- Comment System 💬
- User Profile 👤
- Profile Picture Upload
- Search Posts 🔍
- Docker Support 🐳

---

# ☁️ AWS Services Used

- AWS EC2
- AWS RDS MySQL
- Security Groups
- VPC

---

# 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Gunicorn
- Nginx
- Docker
- GitHub

---

# ⚙️ Run Project

```bash
pip install -r requirements.txt
python3 app.py
```

---

# 🐳 Docker

```bash
sudo docker build -t flask-blog .
sudo docker run -d -p 5000:5000 flask-blog
```
